Nuestro proyecto se llama SpotIA, el cual es una página que permite a los clientes poder registrar reservas dependiendo del local que decidan. Además, la página permite registrar métodos de pago, ubicaciones (incluyendo comunas y regiones), servicios que ofrecen los locales y el tipo de local que es.
